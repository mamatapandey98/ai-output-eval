## Scoring interpretation

The principal false-penalty bug was comparing each page result to the same document-level reference. Extraction now scores the first non-empty document answer once, retaining page values as diagnostics. Other general rules clear fiscal-range, exact contact email/name, byline, publication-article, annotated-amount, zero-balance-dash, and explicit `<UNKNOWN>` formatting/abstention mismatches; free-text numeric differences no longer trigger the typed-number hard cap. Explicit amount/date/ID/period mismatches remain protected.

The ungradable cases are excluded only from the manual quality interpretation; existing numeric scores are preserved for traceability and still include them. Supported paraphrases are called out rather than assigned arbitrary replacement scores. The ledger does not promise every remaining fractional score is a factual error or every paraphrase is perfect.
